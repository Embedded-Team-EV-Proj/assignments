# Group 4 Assignments

Weekly assignments for **Group 4: Embedded Systems** (DawgDrive Innovators, UGA Cardboard EV Project).

A new assignment goes up every week. Each one has its own folder. Open the folder and read its `README.md`.

| Week | Assignment | Due | Turn in |
|---|---|---|---|
| 1 | [ESP32 basics](week-01-esp32-basics/) | Thu 10/22 noon | Group 4 Discord channel |
| 2 | [Drive track and Input track](week-02-drive-and-input/) | Wed 10/28 noon | Discord DM to Morris |

## How it works
- Everything so far runs in [Wokwi](https://wokwi.com) in your browser. No hardware needed yet.
- Turn in what each assignment asks for, the way it says (usually Discord).
- Stuck? Ask in the Group 4 Discord channel. Asking is part of the assignment.
